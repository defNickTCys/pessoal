# Fontes verificadas

As fontes primárias usadas no PRD estão em
[`../prd/PRD-alethe-onboarding-opencode.md`](../prd/PRD-alethe-onboarding-opencode.md).

## Regra de uso

- fontes oficiais definem comportamento de CLI, billing e quota;
- arquivos locais definem o inventário fornecido pelo usuário;
- divergências devem ser registradas no `STATE.md`;
- snippets de busca não substituem a página oficial;
- preços e limites devem ter data de verificação antes de entrar em `alethe-prices.json`.

## Observação sobre a sessão

Esta sessão é adequada para preparar e revisar o material, mas não prova o estado do ambiente
local de execução. O onboarding interativo deve ser executado no computador onde os CLIs e as
autenticações estão disponíveis.
